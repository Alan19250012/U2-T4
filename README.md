# U2 T4 - Landing page de NovaSoft

Landing page de una empresa ficticia de desarrollo de software. Hecha con HTML, CSS propio, JavaScript, Bootstrap Icons y GSAP.

## Secciones

- Navbar
- Hero
- Servicios
- Tecnologias utilizadas
- Estadisticas
- Proyectos
- Calculadora de costo
- Formulario de contacto
- Footer

## Tecnologias

- HTML
- CSS propio
- JavaScript
- Bootstrap Icons (CDN)
- GSAP.js (CDN)

## Animaciones con GSAP

1. Entrada del Hero al cargar la pagina.
2. Aparicion de las tarjetas de servicios al hacer scroll.
3. Contador animado de las estadisticas al hacer scroll.

## Interaccion con JavaScript

La seccion "Calcula el costo de tu proyecto" multiplica la cantidad de paginas por el precio por pagina y muestra el resultado modificando el elemento con id `costo-estimado`.
